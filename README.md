# 文言实词限时训练

这是一个面向高中语文课堂和个人训练的本地浏览器答题系统，当前聚焦浙江新高考语境下的文言实词限时辨析。学生可以按教材范围进入限时训练，根据课内原句选择目标词的释义；教师可以在本机管理题库、审查题目并维护排行榜。

项目采用“浏览器答题页＋本地服务＋文件题库”的轻量结构，适合教室电脑直接运行，也方便后续继续补充教材、文章和题目。当前正式范围为统编版必修上、下册与选择性必修上、中、下册的课内单句实词释义题。

本项目的题库属于教师在本机维护的运行数据，不随公开源码和发布包分发。公开仓库保持代码与空白数据目录；首次启动时会自动创建空白题库，教师可以在管理后台导入自己的题库。题目仍以单字或最小可释义词单位为考点，候选题需经教师复核后才进入学生答题。

## 本地运行

最简单的方式：双击项目根目录中的 `启动文言实词训练.bat`，它会自动启动本地服务并打开学生答题页。

使用“免 Python 发布包”时，直接解压并双击 `文言实词限时训练.exe` 即可，无需安装 Python；关闭 EXE 打开的黑色窗口即可停止服务。源代码项目则仍需要 Python 来运行 `tools/run_server.py`。

当前发布版本统一按版本号归档在 `release/`；最新版本为 `release/v1.4.5`。当前版本的源码包和 Windows 包均为不含题库的代码包，旧版归档仅供历史参考；以后升级时新增版本号目录，不覆盖旧版本。

如果双击启动文件后提示没有找到 Python，再使用下面的手动方式：

由于网页需要通过本地服务读写题库和排行榜，不能直接双击 `index.html`。请在项目根目录启动；如果 `data/questions.json` 不存在，服务会自动创建空白题库：

```powershell
python tools/run_server.py --port 8000
```

然后打开 <http://localhost:8000>。

## 管理后台

打开 <http://localhost:8000/admin.html>，也可以从学生答题页底部点击“进入管理后台”。

管理后台首次启动时的访问密码为 `pc123456`；进入“管理员密码”页可以填写当前密码、新密码和确认新密码，保存后会立即退出后台，必须使用新密码重新登录。密码以哈希形式写入 `%LOCALAPPDATA%/WenyanQuiz/admin-settings.json`，这是用于避免学生误入的本机入口保护，并非服务器级账户系统。系统另有一个固定检修入口，不能在后台修改，不在网页或说明文件中展示。

- 题库管理：按教材册、文章和关键词查找题目；新增、修改或删除题目，也可以修改题型、原句、题干、四个选项、正确答案和解析。考查实词不再重复手打：先填写原句，再在原句选区中拖选目标字词并点击“将选中文字设为考点”；同一个词出现多次时可直接选中具体位置。
- 题库结构：可以新增题型、教材册和所属文章；正在被题目使用的项目不能删除，避免题目失去归属。
- 题库文件：支持导出当前完整题库、下载合并的 `JSON模版导入说明.md`；“新增导入题库（合并）”按文章、考点、原句、出现位置和题目内容去重，完全重复题自动跳过，细节不同的同核心题会标记为“重复候选”并暂不进入答题，导入题自动分配本机编号；“导入并替换（谨慎）”保留给完整替换场景。题库管理还会记录导入/导出历史，历史记录只读；新版本产生的导入批次可以在二次确认后撤销，撤销操作不可逆并会追加审计记录。
- 管理员密码：独立的后台选项，要求填写当前密码，并将新密码确认两遍；修改成功后当前授权立即失效。
- 快速审查：将所有题目按横条连续展开，老师滚动查看后可直接确认答案正确、标记待修改或跳过；错误选项问题和审查备注均可选填。
- 排行榜管理：新增、修改、删除或清空成绩。
- 答题记录：查看每局的姓名、答题时间、用时、得分和完整题目快照；记录可折叠或恢复，已折叠与未折叠分别只保留最近 1 个月内的最新 100 条，超出各自范围的记录会清除并在清除前备份；支持批量折叠/恢复、JSON 导入和导出。
- 题库和审查记录由本地服务写入应用旁边的 `data` 文件夹，不依赖浏览器缓存；公开仓库和 release 不携带这些本地数据，源码运行时就是项目 `data`，免 Python EXE 运行时就是 EXE 旁边的 `data`。
- 题库、审查记录和密码保存前会先生成旧文件备份，并通过临时文件替换方式写盘；排行榜和答题记录及其备份保存在 `%LOCALAPPDATA%/WenyanQuiz/`。答题记录支持折叠或恢复，并分别自动清理超过最近 1 个月或各自最新 100 条范围的记录；自动清理前会生成备份，支持批量处理以及 JSON 导入导出。管理写接口使用仅存在于当前服务内存的会话令牌，题库保存带版本冲突检查；服务默认只监听本机 `127.0.0.1`，不对局域网开放。
- 只要应用目录具有写入权限，后台显示“已保存到 questions.json”就代表服务已完成硬盘写入；若目录只读、文件被占用或杀毒软件拦截，后台会显示保存错误，不会伪装成浏览器内保存。

## 检查更新与数据保护

程序启动时会在后台查询本项目的 GitHub Releases。只有进入管理员后台后，检测到更高版本才会显示更新提示；断网、GitHub 暂时不可用或已经是最新版时不会弹窗。右上角“检查更新”可以随时重新检查。

确认更新后，程序会先下载并校验不含题库的更新包，再由更新助手自动重启和替换程序文件，不需要手动下载安装。源码目录存在未提交修改时会跳过自动替换，避免覆盖本地代码。

更新包严格不包含 `data/`、题库 JSON、审查记录和题库生成素材。更新助手也会拒绝包含这些路径或路径穿越内容的压缩包；应用旁的 `data/` 以及 `%LOCALAPPDATA%/WenyanQuiz/` 中的题库、排行榜、答题记录和管理员配置不会被更新流程删除或覆盖。

## 当前规则

- 限时 120 秒
- 后台“计分机制”可以在固定计分和连续表现之间切换，规则对新开的训练局生效，正在进行的训练局不变
- 固定计分：答对一题加 1 分，答错一题扣 1 分
- 连续表现默认：连续答对 2 题后，从第 3 题起每题加 2 分；连续答错 2 题后，从第 3 题起每题扣 2 分；答对和答错会互相重置连续次数
- 后台“计分机制”可以设置每局答题时长（10 秒至 60 分钟），并将连续答对/答错的触发题数限制在 1-5 题
- 分数允许为负数；学生端会用短促的颜色、图标和分数徽章区分基础得分与连击/连续错误得分
- 四选一纯猜的期望收益为负分，不鼓励盲目乱点
- 首页可以同时勾选多本必修/选择性必修教材册和多篇具体文章，“全部教材册”“全部文章”支持一键全选
- 每局随机打乱题目和选项，答题页面不显示总题数或答题比例
- 答题字号可在答题页调节至最大 200%
- 在规定时间内答完全部题目时，结果页会提示“所有题目已答完”
- 结果页可填写名字并加入排行榜，排行榜写入 `%LOCALAPPDATA%/WenyanQuiz/leaderboard.json`；成绩同时保存教材/篇目范围、答题时长和计分规则快照，同分时先提交者优先
- 同一台电脑上通过本网站答题的学生，共用同一份排行榜；关闭或重开浏览器后成绩仍保留。完整答题记录只在管理员后台查看，学生端不提供历史记录入口
- 当前没有账号、云端同步或跨电脑排行榜

## 题库文件与公开分发边界

- `data/questions.json`：网页实际读取的标准题库。它是本机私有运行数据，首次启动时会自动生成空白文件；教师可通过后台导入包含题型、教材册、文章和题目的 JSON。公开 GitHub 仓库和 release 包不包含真实题库
- 题目若无法定位 `word` 在 `sentence` 中的划线位置，会保留原题并标记 `reviewStatus: "abnormal"`；学生端自动跳过，老师可在题库管理中修复后恢复
- `data/expanded_question_specs.json`、`data/questions-complex-archive.json`：本机题库制作或历史归档素材，不提交到公开仓库，也不放入 release
- `%LOCALAPPDATA%/WenyanQuiz/leaderboard.json`：所有浏览器和应用版本共用的本机排行榜；旧版本的 `data/leaderboard.json` 只用于首次启动时迁移
- `%LOCALAPPDATA%/WenyanQuiz/answer-records.json`：所有浏览器和应用版本共用的本机答题记录；已折叠与未折叠分别只保留最近 1 个月内的最新 100 条，应用升级不会覆盖
- `%LOCALAPPDATA%/WenyanQuiz/answer-records-backups/`：答题记录保存、折叠、恢复或自动清理前的自动备份；自动轮转保留最近 100 份且不超过 90 天
- `data/question-bank-history.json`：本机题库导入、导出和撤销导入的只读历史；导入记录不能删除或修改，撤销通过追加事件完成
- `data/question-reviews.json`：本机教师审查状态、建议答案、选项问题和审查备注
- `data/backups/`：后台每次保存前自动生成的旧文件备份
- `%LOCALAPPDATA%/WenyanQuiz/backups/`：排行榜每次保存前自动生成的旧文件备份
- `tools/run_server.py`：本地服务，负责提供网页和持久化保存接口；学生结果通过幂等的 `/api/quiz-results` 提交，不使用管理员写接口

GitHub 仓库、源码 ZIP、Windows release ZIP 都不包含真实题库、审查记录、题库导入历史或题库制作素材。发布包可以直接启动，但初始状态没有可答题目；管理员导入题库后，题库会固化保存在本机，不会因升级代码包而被覆盖。

题库 JSON 的完整格式、可直接复制的模版和当前全部目录，可以在后台“题库管理”区域下载唯一文件 `JSON模版导入说明.md`。文件会列出当前全部题型、教材册和篇目 ID；`id` 是程序识别用的本机编号，`label`/`title` 是页面显示名称，题目必须用 `type` 引用题型 ID、用 `articleId` 引用篇目 ID。题目源数据采用“文章归属、目标词、原句、正确义项、固定干扰项、解析、来源和审核状态”的结构。一道题只保存一个考点词：同一句要考两个不同词时，建立两条题目记录并分别填写 `word`、`targetOccurrence`、`targetStart`、选项和解析；同一个词在句中出现多次时，用 `targetOccurrence` 指明第几处，后台选词会自动写入 `targetStart`，服务端会校验两者一致。扩容候选题的来源包括课文注释、文言实词例句和人工整理；正式使用前应依据统编版课文、课下注释及人民教育出版社《高中语文学习任务导引》参考答案逐题复核。后续增加题库时，可以让其他 AI 按该文件制作 JSON，再使用“新增导入题库（合并）”追加；系统会按内容去重，不能只按 ID 判断重复。
