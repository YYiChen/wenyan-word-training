# 文言实词限时训练

一个面向高中语文课堂与个人练习的本地文言实词限时答题系统。项目提供学生答题页和教师管理后台，支持按教材范围训练、题库导入与维护、排行榜、答题记录和本机持久化。

## 主要功能

- 按教材册与篇目选择训练范围
- 限时四选一答题，自动打乱题目与选项
- 教师后台管理题目、目录、审查状态和成绩
- 本地保存排行榜、答题记录与管理员设置
- 服务默认仅监听 `127.0.0.1`
- 支持打包为免 Python 的 Windows 可执行版本

## 运行方式

项目源码需要 Python 3。克隆仓库后，先自行准备题库文件 `data/questions.json`，然后运行：

```powershell
python tools/run_server.py --port 8000
```

浏览器访问 <http://localhost:8000>；管理后台位于 <http://localhost:8000/admin.html>。

Windows 用户也可以双击 `启动文言实词训练.bat` 启动，使用 `关闭文言实词训练.bat` 停止。

## 题库说明

本公开仓库仅包含应用源码，不包含项目实际使用的题库、审查记录、备份文件或题库生成素材。运行前请在本地创建或导入符合程序格式的 `data/questions.json`；这些文件已由 `.gitignore` 排除，不会被普通 Git 提交带入公开仓库。

管理后台支持导入、导出和维护题库。请确保你使用的题目内容拥有合法授权。

## 数据位置

- 应用题库与审查记录：项目或可执行文件旁的 `data/`
- 排行榜、答题记录和管理员设置：`%LOCALAPPDATA%/WenyanQuiz/`

本项目目前是本地工具，不包含账号系统、云端同步或跨电脑排行榜。

## 技术栈

- Python 标准库本地 HTTP 服务
- Windows 批处理启动脚本
