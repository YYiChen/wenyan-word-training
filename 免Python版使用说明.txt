文言实词限时训练（免 Python 版）

1. 请先完整解压压缩包，不要只把 EXE 单独复制出来。
2. 直接双击“文言实词限时训练.exe”，浏览器会自动打开学生答题页；本发布包不需要 BAT 文件，黑色服务窗口会使用文言实词训练应用图标。
3. 管理后台地址：http://127.0.0.1:8000/admin.html
   管理密码：pc123456
   后台“管理员密码”选项可以修改密码；需要填写当前密码，并将新密码确认两遍，保存后必须使用新密码重新登录。
4. 本发布包不内置题库、审查记录或导入历史。首次启动时会自动在应用旁边创建空白 data 文件夹；请进入管理后台导入题库，保存后题库会一直保存在本机，不会随应用升级包覆盖。排行榜写入电脑用户目录 `%LOCALAPPDATA%\WenyanQuiz`，排行榜备份也在那里。
5. 每局答题结束后会自动保存答题记录；已折叠、未折叠分别只保留最近 1 个月内的最新 100 条，超出各自范围的记录会清除并在清除前备份。首页“查看答题记录”可以查看题目和作答情况；管理员还可以在后台折叠或恢复记录，并使用 JSON 导入和导出。
6. 本版本不需要安装 Python。程序会在后台尝试检查 GitHub Release 更新；断网时不影响本地答题，也不会上传题库、排行榜或答题记录。
7. 使用结束后，直接关闭 EXE 打开的黑色窗口即可停止本地服务。

8. 答题页面右上角可以调节字号，最大支持 200%。
9. 管理后台“计分机制”可以切换固定计分或连续表现计分；保存后新开的训练局生效。
   这里也可以设置每局答题时长（10 秒至 60 分钟）；连续答对和连续答错的触发题数为 1-5 题。
10. 题库中无法定位划线考点的题目不会被删除，会标记为“异常待复核”，学生答题时自动跳过；重新在后台选择考点并保存后即可恢复。
11. 新增导入题库（合并）按文章、考点词、原句、出现位置和题目内容去重，不按导入 ID 判断；完全重复题会跳过，细节不同的同核心题会标记为“重复候选”，在后台快速审查处理前不会进入答题，导入题会自动分配本机编号。
12. 点击“检查更新”后会立即显示检查状态；已经是最新版、GitHub 无法连接或本地源码有修改时会弹窗说明。

说明：再次启动新 EXE 时，如果旧版本的“文言实词限时训练.exe”仍在运行，程序会先关闭旧服务，再启动新服务。

更新说明：管理员确认更新后，程序会自动下载、校验并重启更新，不需要手动安装；题库、排行榜和答题记录会保留。
