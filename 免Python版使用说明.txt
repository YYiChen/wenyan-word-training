文言实词限时训练（免 Python 版）

1. 请先完整解压压缩包，不要只把 EXE 单独复制出来。
2. 直接双击“文言实词限时训练.exe”，浏览器会自动打开学生答题页；本发布包不需要 BAT 文件。
3. 管理后台地址：http://127.0.0.1:8000/admin.html
   管理密码：pc123456
   后台“管理员密码”选项可以修改密码；需要填写当前密码，并将新密码确认两遍，保存后必须使用新密码重新登录。
4. 后台保存的题库和审查记录写入应用旁边的 data 文件夹；排行榜写入电脑用户目录 `%LOCALAPPDATA%\WenyanQuiz`，排行榜备份也在那里，不会随应用压缩包升级而覆盖。
5. 每局答题结束后会自动保存完整答题记录；首页“查看答题记录”可以查看题目和作答情况。管理员不能删除答题记录，只能在后台折叠或恢复记录，也支持批量处理以及答题记录 JSON 导入和导出。
6. 本版本不需要安装 Python。程序会在后台尝试检查 GitHub Release 更新；断网时不影响本地答题，也不会上传题库、排行榜或答题记录。
7. 使用结束后，直接关闭 EXE 打开的黑色窗口即可停止本地服务。

8. 答题页面右上角可以调节字号，最大支持 200%。

说明：再次启动新 EXE 时，如果旧版本的“文言实词限时训练.exe”仍在运行，程序会先关闭旧服务，再启动新服务。

更新说明：管理员确认更新后，程序会自动下载、校验并重启更新，不需要手动安装；题库、排行榜和答题记录会保留。
